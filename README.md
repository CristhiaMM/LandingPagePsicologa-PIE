# Landing Page - Psicologa Vanessa A. Gonçalves

Landing page institucional para a psicóloga **Vanessa Andrade Gonçalves (CRP 08/37740)**, apresentando sua atuação profissional, especialidades e formas de contato e agendamento

 Deploy: [landingpagepsicologa-pie.vercel.app](https://landingpagepsicologa-pie.vercel.app)

## Sobre o projeto

Site de uma unica pagina desenvolvido para apresentar os serviços da profissional, com navegação por ancoras entre as seções e botão de agendamento direto via WhatsApp

## Seções

- **Hero** - apresentação inicial e numeros de experiência 
- **Sobre mim** - apresentação profissional
- **Especialidades** - áreas de atuação (TCC, avaliação psicologica, psicologia do esporte)
- **Como funciona** - etapas do atendimento
- **Depoimentos** - avaliações de pacientes
- **FAQ** - perguntas frequentes 
- **Agendar** - contato via whatsapp, telefone e e-mail

## Tecnologias

- HTML5
- CSS3 (com layout responsivo)
- JavaScript (vanilla)
